# Project 1 — Sales Data Analysis

**Objective:** analyze retail transactions and turn raw sales records into business insights.

## Included
- `data/sales_transactions.csv` — synthetic transaction data
- `notebooks/sales_analysis.ipynb` — complete analysis workflow
- `reports/` — generated when the notebook is run

## Questions answered
- What are total revenue, profit, average order value and margin?
- How do monthly revenue and profit change?
- Which products, categories, regions and channels perform best?
- How do discounts relate to profit margin?

## Run
Open `notebooks/sales_analysis.ipynb` and run all cells from top to bottom.

**Data disclosure:** the dataset is synthetic and intended for learning only.
